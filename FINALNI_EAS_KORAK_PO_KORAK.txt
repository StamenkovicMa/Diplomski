MONEYMATE — FINALNI EAS POSTUPAK

VAŽNO:
- Prekopiraj svoj .env fajl u ovaj folder za lokalni Expo test.
- Za EAS cloud build unesi iste promenljive u Expo/EAS projekat.
- Nemoj stavljati secret/service_role Supabase ključ. Koristi publishable key.

A) PROVERA PRE BUILDA

1. Otvori terminal u folderu projekta.
2. Pokreni:
   npm install
   npx expo install --fix
   npx expo-doctor

3. Lokalni test:
   npx expo start --lan --clear

B) EXPO NALOG I POVEZIVANJE PROJEKTA

1. Instalacija EAS CLI:
   npm install -g eas-cli

2. Prijava:
   eas login

3. Povezivanje projekta:
   eas init

Prihvati kreiranje novog Expo projekta. Komanda će automatski dodati
extra.eas.projectId u app.json.

C) EAS PROMENLJIVE

U Expo dashboardu za povezani projekat dodaj:
EXPO_PUBLIC_SUPABASE_URL
EXPO_PUBLIC_SUPABASE_ANON_KEY

Vrednosti su iste kao u lokalnom .env fajlu.

D) ANDROID APK KOJI SE DIREKTNO INSTALIRA

eas build --platform android --profile preview

Posle builda dobijaš link i QR za preuzimanje APK fajla.

E) ANDROID PRODUCTION ZA PLAY STORE

eas build --platform android --profile production

Production Android build je AAB za Google Play.

F) iPHONE

Preview iOS build zahteva Apple Developer nalog i registrovanje uređaja.
Za App Store/TestFlight koristi:

eas build --platform ios --profile production

G) KASNIJE IZMENE

Kada promeniš JavaScript kod, napravi novi build ili podesi EAS Update.
Kada promeniš native plugin, permissions ili app.json, obavezan je novi build.
