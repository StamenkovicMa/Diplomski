PROVERA QR SKENERA

1. Kopiraj .env u ovaj folder.
2. Pokreni:
   npm install
   npx expo install --fix
   npx expo-doctor
   npx expo start --lan --clear

3. Na pocetnoj strani mora da se vidi veliko dugme:
   SKENIRAJ FISKALNI QR

4. Klikom se odmah otvara kamera.
5. Usmeri kameru na QR sa fiskalnog racuna.
6. Posle citanja kamera se zatvara i otvara forma troska.
7. Proveri:
   - naziv prodavca
   - iznos
   - datum
   - valuta RSD
   - kategorija
   - QR link
8. Ispravi podatke ako je potrebno i klikni Dodaj transakciju.

Ako koristis vec instalirani EAS build, mora se napraviti NOVI BUILD jer expo-camera menja native aplikaciju:
eas build --platform android --profile preview
ili
eas build --platform ios --profile preview
