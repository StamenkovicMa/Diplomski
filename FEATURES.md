# Funkcionalni pregled

## Ekrani
1. Početna
2. Transakcije
3. Budžeti
4. Ciljevi
5. Izveštaji
6. Podešavanja

## Čuvanje
Svi podaci se čuvaju lokalno pod ključem `moneymate_complete_v2`. Aplikacija ne zahteva nalog, backend ili API ključ.

## Gestovi
- Dodir unosa: izmena
- Dugi pritisak: brisanje

- Dugme **Kupi to** kada cilj dostigne 100%; automatsko evidentiranje troška i uklanjanje iz ukupnog stanja

- 30 različitih kategorija prihoda

- Pregledan izbor kategorija u mreži od dve kolone
- Kategorije grupisane po oblastima sa ikonama
- Pretraga kategorija pri dodavanju transakcije i budžeta
- Jasniji izbor između prihoda i troška
