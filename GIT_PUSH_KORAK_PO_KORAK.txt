MONEYMATE 2.1.0 — REFAKTOR STRUKTURE

Pokretanje:
npm install
npx expo install --fix
npx expo start --lan --clear

Proveri da rade:
- login/registracija
- transakcije
- QR skener
- ciljevi
- ponavljajuće transakcije
- izveštaji i predikcija

Git:
git status
git add .
git commit -m "Refactor application structure"
git push origin master

App.js je sada samo entry point.
Glavna logika je razdvojena u src/config, src/constants, src/services i src/utils.
